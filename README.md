# MiniCparser
Semester long project where i had to implement parsing typing  code generation and testing in python  .
The codebase was not provided by me but the implementation is .
Parsing : Parsed MiniC which is a lightweight version of C using python 
Typing : Wrote typing Rules for MiniC
Code Generation : generated assembly code (RISC V) from previously implemented parsing rules 
Testing : wrote test for the 3 parts
